## FAQ

### 如何编辑字幕文件？

.srt 字幕文件是一个文本文件，简单的修改，可以直接在线编辑，然后提交修改。如果是复杂的操作，比如逐条校对，推荐使用字幕编辑软件比如[Aegisub](https://aegisub.org/)去同时加载字幕和音频。

### VLC播放器不显示字幕？

音频 (Audio) 菜单 -> 可视化 (Visualization) -> 选择任一种可视化效果，比如 波形 Waveform。
